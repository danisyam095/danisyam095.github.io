# 🌿 Dani Syam — Personal Portfolio

Portofolio pribadi yang dibuat menggunakan **Vite + React + shadcn/ui** untuk menampilkan profil profesional, proyek, dan kontak saya secara elegan dan minimalis.

---

## ✨ Fitur Utama

- 🎨 **UI Clean & Minimalis** — Menggunakan [shadcn/ui](https://ui.shadcn.com) dan TailwindCSS.
- ⚡ **Performa Cepat** — Berbasis [Vite](https://vitejs.dev) dengan React + TypeScript.
- 🧩 **Komponen Modular** — Navbar, Hero, About, Projects, Contact, dan Footer.
- 💬 **Contact Form** — Terintegrasi dengan [EmailJS](https://www.emailjs.com/).
- 💾 **CV Download** — Tombol unduh langsung dari bagian Hero.
- 🌐 **LinkedIn & GitHub** — Tautan profesional siap pakai.
- 🎞️ **Animasi Lembut** — Powered by [Framer Motion](https://www.framer.com/motion/).

---

## 🧱 Tech Stack

| Tool | Fungsi |
|------|--------|
| [Vite](https://vitejs.dev) | Build tool super cepat |
| [React + TypeScript](https://react.dev) | Library UI |
| [shadcn/ui](https://ui.shadcn.com) | Komponen desain elegan berbasis Radix + Tailwind |
| [TailwindCSS](https://tailwindcss.com) | Utility-first styling |
| [Framer Motion](https://www.framer.com/motion/) | Animasi halus |
| [Lucide Icons](https://lucide.dev) | Ikon ringan dan modern |
| [React Hook Form](https://react-hook-form.com/) | Validasi form |
| [EmailJS](https://www.emailjs.com) | Kirim pesan tanpa backend |
